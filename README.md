# ESP32-AI

面向 [Waveshare ESP32-S3-Touch-LCD-3.5](https://docs.waveshare.net/ESP32-S3-Touch-LCD-3.5) 的中文触控智能终端固件。

项目基于小智 AI `v2.4.0` 与 ESP-IDF 开发，在保留小智语音交互能力的基础上，加入了适配 480×320 横屏的 LVGL 主页、弧形应用菜单、天气、时间、MicroSD 多媒体以及常用工具应用。

> 当前应用版本：**V1.3**  
> 目标硬件：**ESP32-S3-Touch-LCD-3.5**  
> 开发环境：**ESP-IDF 5.5.4**

## V1.3 版本介绍

V1.3 重点完善了应用系统、联网能力和界面流畅度：

- 应用 UI 更新周期由 100 ms 优化为 16 ms，与 LVGL 底层刷新周期一致，目标刷新率约 60 FPS。
- 优化大号时钟字体重绘策略，只在秒、分钟或日期发生变化时刷新，降低无效绘制和 LCD 总线占用。
- 修复长时间运行、反复切换应用或更换字体后可能出现的白屏、卡死和重启问题。
- 新增小智联网同步时间，可在设置页面一键校时，同时保留手动日期和时间设置。
- 接入 Open-Meteo 七日天气，可在设置中修改经纬度，无需天气 API Key。
- 完善 MicroSD 媒体与文件功能，支持图片、小说、MJPEG 视频、MP3 音乐、CMJ 漫画和文件管理。
- 优化触摸唤醒：进入低亮度后，点击或滑动屏幕可恢复原亮度。
- 修复计算器符号、中文字体、日历、倒计时、2048 滑动及应用切换等显示和交互问题。

16 ms 是软件目标刷新周期。复杂页面的实际帧率仍取决于 ESP32-S3 绘制负载、LCD SPI 带宽、图片解码和存储读取速度。

## 主要功能

### 小智 AI

- 保留小智 AI 作为独立应用界面。
- 支持语音唤醒、语音识别、AI 对话和语音播报。
- 使用小智官方联网与设备激活流程，可在 [xiaozhi.me](https://xiaozhi.me/) 管理设备。
- BOOT 键长按可在智能终端主页与小智 AI 页面之间切换。
- 在小智页面短按 BOOT 键可开始或结束语音交互。

### 中文触控主页

- 480×320 横屏全尺寸布局。
- 水平滑动的弧形应用菜单，图标根据位置缩放并沿圆弧排列。
- 主页显示小时、分钟、秒和天气入口。
- 点击天气图标可直接进入七日天气页面。
- 应用内短按 BOOT 键可返回主页。

### 应用列表

菜单提供 12 个应用，天气通过主页组件进入，共 13 个全屏应用：

1. 时钟与自定义壁纸
2. 图片浏览与自动轮播
3. TXT 小说阅读
4. MJPEG 视频播放
5. MP3 音乐播放
6. 2048 游戏
7. 计算器
8. 秒表与倒计时
9. 日历
10. CMJ 漫画阅读
11. 设置
12. 文件管理
13. Open-Meteo 七日天气

### 设置与电源管理

- 小智联网同步时间和手动时间设置。
- Wi-Fi 配网入口。
- 时钟壁纸选择。
- 图片轮播间隔设置。
- 天气经纬度设置。
- MicroSD 重新扫描。
- 电池状态查看与亮度管理。
- 60 秒无操作后背光降至 20%，触摸后恢复；持续无操作时按现有电源策略关机。

## MicroSD 目录与格式

不插 MicroSD 卡也可以使用主页、小智 AI、天气、时钟、游戏、计算器、秒表、倒计时、日历和设置等功能。媒体类应用需要 MicroSD 卡，并按下表放置文件：

| 目录 | 支持格式 | 用途 |
| --- | --- | --- |
| `/壁纸` | `.jpg`、`.jpeg`、`.sjpg` | 时钟壁纸 |
| `/图片` | `.jpg`、`.jpeg`、`.sjpg` | 图片浏览 |
| `/小说` | UTF-8 `.txt` | 小说阅读 |
| `/视频` | `.mjpeg`、`.mjpg` | 视频播放 |
| `/音乐` | `.mp3` | 音乐播放 |
| `/漫画` | `.cmj` | 漫画阅读 |

存储驱动采用 Waveshare 官方例程对应的 1-bit SDMMC 接线，并由各应用共享同一挂载实例。

## 编译与烧录

### 环境要求

- ESP-IDF 5.5.4
- Python 与 ESP-IDF 配套虚拟环境
- 支持数据传输的 USB-C 线
- 16 MB Flash 的 Waveshare ESP32-S3-Touch-LCD-3.5

### 命令行方式

```powershell
idf.py set-target esp32s3
idf.py menuconfig
idf.py build
idf.py -p COM10 flash monitor
```

在 `menuconfig` 的 `Xiaozhi Assistant → Board Type` 中选择：

```text
Waveshare ESP32-S3-Touch-LCD-3.5
```

请把 `COM10` 替换为设备管理器中实际出现的串口。也可以用 VS Code 打开工程后，通过 ESP-IDF 插件选择串口并点击烧录。

编译产物默认位于：

```text
build/ESP32-S3-AI.bin
```

## 首次启动

1. 烧录完成后等待设备启动。
2. 按屏幕或语音提示完成 Wi-Fi 配网。
3. 若屏幕显示设备激活码，请登录 [xiaozhi.me](https://xiaozhi.me/) 添加设备。
4. 长按 BOOT 键切换到智能终端主页。
5. 在设置中配置天气经纬度，或使用小智联网同步时间。

## 当前限制

- 约 60 FPS 指 16 ms 的目标 UI 更新周期，不代表所有页面都能稳定输出完整 60 帧。
- 视频仅支持当前固件实现的 MJPEG/MJPG 格式，不支持 MP4、H.264 等容器或编码。
- 天气位置当前使用经纬度配置，不提供中文城市搜索输入法。
- 媒体读取速度和播放流畅度会受到 MicroSD 卡性能及文件编码参数影响。
- 固件应用分区剩余空间有限，继续增加大型字体、图片或功能前应检查 Flash 占用。
