# 教学型详细中文注释

## 默认要求

- 对项目自研的 `.c`、`.h` 代码使用中文注释，第三方库、自动生成文件和协议固定文本不做批量改写。
- 让初学者仅阅读源码即可理解初始化顺序、外设配置、引脚含义、参数作用和数据流。
- 新增或实质修改函数时补齐函数头、步骤注释和关键语句注释；不要只为了统一注释改动无关旧代码。

## 函数头

使用以下格式说明函数、参数和返回值：

```c
/**
  * 函    数：初始化 ADC 和 DMA 多通道采集
  * 参    数：buffer  存放转换结果的缓冲区
  *           count   缓冲区元素数量，必须与 ADC 通道数一致
  * 返 回 值：ERROR_OK 初始化成功；其他值表示具体错误
  * 注意事项：调用前必须完成系统时钟初始化
  */
ErrorCode_t BSP_ADC_Init(uint16_t *buffer, uint16_t count)
{
}
```

- 无参数写“无”，无返回值写“无”。
- 参数说明包含含义、范围、单位或缓冲区长度关系。
- 存在调用顺序、阻塞、ISR、线程安全或硬件限制时增加“注意事项”。
- 简单 `main`、中断入口或由工具固定生成的函数可以沿用工程模板，但仍需解释关键业务行为。

## 步骤块注释

在初始化或复杂流程中，用简短块注释分隔阶段：

```c
/*开启外设时钟*/
/*配置 GPIO 模拟输入*/
/*配置 ADC 规则组通道*/
/*配置 DMA 循环搬运*/
/*使能 ADC 并执行校准*/
```

- 注释描述当前代码块的目的，不使用“处理一下”“相关配置”等模糊文字。
- 保持步骤顺序与硬件实际依赖一致。

## 关键语句右侧注释

对寄存器、HAL/SPL 配置、引脚、电平、时钟、DMA、定时器和中断语句进行逐项说明：

```c
RCC_APB2PeriphClockCmd(RCC_APB2Periph_ADC1, ENABLE);          //开启 ADC1 外设时钟
RCC_ADCCLKConfig(RCC_PCLK2_Div6);                             //配置 ADC 时钟为 72 MHz / 6 = 12 MHz
GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0 | GPIO_Pin_1;        //选择 PA0 和 PA1 作为模拟输入通道
DMA_InitStructure.DMA_Mode = DMA_Mode_Circular;               //使用循环模式，持续覆盖更新采样数组
GPIO_ResetBits(GPIOA, GPIO_Pin_1);                            //输出低电平，点亮低电平有效的 LED1
```

- 解释“配置成什么、为什么、产生什么效果”，不要只重复函数名。
- 明确数字的计算来源、范围和单位，例如 `72 MHz / 6 = 12 MHz`。
- 明确低电平有效、上拉、复用、通道号、DMA 方向等容易误解的硬件语义。
- 相邻注释可适度对齐，但不得为了对齐造成大范围无关格式修改。

## 变量与数据

对全局数据、共享缓冲区、状态和硬件映射增加所有权或用途说明：

```c
static uint16_t s_adcValues[4];       //保存 4 个 ADC 通道的最新转换结果，仅由采集模块更新
```

共享于 DMA、ISR 或任务的数据还需说明写入者、读取者、更新时机和同步方式。不要仅靠 `volatile` 解释并发安全。

## 注释质量检查

- 修改代码后同步检查注释中的引脚、通道、频率、范围和返回值。
- 删除已经失效或与代码矛盾的注释。
- 不注释每个大括号、普通赋值或显然循环；把详细度集中在硬件行为和关键流程。
- 不在第三方库或自动生成代码中手工加入大量注释，以免后续重新生成时丢失。
